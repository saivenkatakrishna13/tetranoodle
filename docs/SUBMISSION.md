## Reviewer quick start

1. Copy `.env.example` to `.env` and provide server-side API keys.
2. Run `npm install`.
3. Run `npm run dev` and open the shown local URL.
4. Start from the profile screen, add the fictional Rahul fixture or another profile, then select **Start scholarship research**.

The archive deliberately excludes `.env`, `.data`, `node_modules`, build output and test output. They contain local secrets, private runtime state, or reproducible dependencies rather than submission material.
